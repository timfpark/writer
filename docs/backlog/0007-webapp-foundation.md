## Story

As a contributor or coding agent, I want a minimal, validated `webapp/` folder
that talks to the service only through its contract so that client features
start inside the boundaries [ADR 0001](../adrs/0001-monorepo-structure.md)
set out.

## Context

ADR 0001 places the webapp's manifest, lockfile, Node.js version, `.npmrc`,
configuration example, and generated API client inside `webapp/`. The client is
generated from the service's committed OpenAPI document and checked for
freshness. [ADR 0003](../adrs/0003-webapp-architecture.md) chooses Vite 8,
types generated by openapi-typescript and called through openapi-fetch,
TypeScript 6.0, Oxlint, Prettier, and Vitest, and a development server on
loopback port 5173 that proxies `/api/` to the service. If building reveals a
flaw in that decision, amend the ADR in the same pull request.
[ADR 0004](../adrs/0004-api-conventions.md) names the health endpoint
`GET /api/v1/health` and makes every error an RFC 9457 problem details body,
which the generated client types as `Problem`.

## Scope

* Create `webapp/` with `package.json` (Node.js version in `engines`),
  `package-lock.json`, an `.npmrc` with the proxy and the settings
  [ADR 0003](../adrs/0003-webapp-architecture.md#build-tool-and-runtime)
  lists, and an `.env.example` with no real values.
* Generate the API client into `webapp/src/api/generated/` from the service
  contract and render the service's health status on one page, reaching the
  service through the development server's `/api/` proxy.
* Add a `webapp` phase to `tools/check`, after the `service` phase, running
  the commands ADR 0003 lists, including the client freshness check.
* Apply the root guide's "Adding a subsystem" checklist, including
  `webapp/README.md` with its development port, `webapp/AGENTS.md` with
  Governing decisions and exact commands, port 5173 in the devcontainer's
  `forwardPorts`, and an npm Dependabot entry that uses the proxy registry.

## Acceptance criteria

* [ ] The build tool, client generator, toolchain, and port match
  [ADR 0003](../adrs/0003-webapp-architecture.md), and `webapp/AGENTS.md`
  links it, ADR 0001, and ADR 0004 under Governing decisions.
* [ ] Following `webapp/README.md`, the page shows the service's health status
  on a host and in the development container.
* [ ] Changing the service contract without regenerating the client makes
  `tools/check` exit 1 with a message naming the generated client.
* [ ] `npm config get registry` inside `webapp/` reports the proxy.
* [ ] The root guides list `webapp/` as existing and link its guide.
